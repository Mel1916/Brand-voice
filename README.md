- [`content/website/`](./content/website) — product and category page copy
- [`content/blog/`](./content/blog) — long-form blog content
- [`content/social/`](./content/social) — Instagram/Facebook captions
- [`content/ads/`](./content/ads) — paid ad copy (Meta, Google Search)
